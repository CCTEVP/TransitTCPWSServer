Place your 1080x1920 videos here:

- `no-train.mp4` — played when RET_NO_TRAIN is received (default state)
- `train-arriving.mp4` — played when RET_TRAIN_ARRIVING_15S is received
- `train-arrived.mp4` — played when RET_TRAIN_ARRIVED is received
- `train-departed.mp4` — played when RET_TRAIN_DEPARTED is received

Videos autoplay muted. Only the initial no-train video can be interrupted. While any other video plays, one command may be queued; a different incoming command replaces the queued one.
